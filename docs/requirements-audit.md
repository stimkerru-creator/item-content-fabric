# Соответствие требованиям: Item Content 1.2.0

Дата: 12 ноября 2026. Проверка исходников, автоматических тестов и реальной игры.
Это внутренняя проверка проекта, не независимая внешняя сертификация.

| Требование | Реализовано | Границы |
|---|---|---|
| Отдельный конструктор | Swing/FlatLaf-приложение, список, карточка, PNG, сохранение, экспорт | Требуется Java 17+ |
| Новые реальные ID | Регистрация Item/Block до открытия мира в namespace itemcontent | После изменения нужен перезапуск; до 4096 определений |
| Слитки/компоненты | Обычные предметы с именем, моделью, стаком, огнестойкостью | Не добавляют рецептов и добычи автоматически |
| Еда | Стандартный FoodComponent с голодом, насыщением и флагами | Эффекты новой еды не настраиваются встроенным типом |
| Оружие и инструменты | Настоящие sword/pickaxe/axe/shovel/hoe/bow/crossbow классы | Особые механики сторонних модов принадлежат поставщикам |
| Броня | Слот, защита, прочность, твёрдость, отбрасывание, ремонт и текстуры | Нет специальных эффектов комплекта |
| Блоки | Полный блок, ориентируемые декоративные сундук/печь, грани PNG, добыча и теги | Декорации не имеют инвентаря/работы станка |
| Общая интеграция | Optional entrypoint, схемы полей, фабрика, инспектор и настройка исходника | Не извлекает произвольные Java-поля; мост пишет автор аддона |
| Просмотр установленных предметов | Настоящий снимок client registry, категорий и доступных свойств | Для актуального снимка нужно войти в мир |
| Картинки каталога | Чтение обычных PNG-моделей в фоне; 1059 иконок в проверенной сборке | Нет универсального рендера сложных модовых объектов |
| Настройка существующих предметов | ID/класс сохраняются; имя, стак, огнестойкость и разрешённые свойства | Урон старого меча и свойства старого блока встроенный тип не изменяет |
| Категории | Выбор, свои вкладки, перетаскивание новых и существующих записей | NBT-варианты не перемещаются; изменения применяются после установки |
| Совместимость с прежними файлами | Версии 1 читаются; новые экспорты/списки — версия 2 | Полные исходники с прежними stat-полями резервируются перед сохранением |
| Независимость от Item Parameters | Нет его зависимости, каталога, формул или stat-массивов | Нативные игровые свойства здесь одинаковы для всех экземпляров одного ID |
| Лицензии и границы сборки | MIT; FlatLaf/Gson с лицензиями; GUI и fixture не входят в мод | Проверяется упаковщиком |

## Фактические проверки

43 обычных теста (13 runtime/форматы/API, 30 desktop/схемы/ресурсы/UI) и масштаб интерфейса 1/1.25/1.5.
Отдельный Fabric-сервер выполнил 28 игровых проверок. Реальный клиент создал каталог из 1269 записей,
12 категорий и 1059 иконок; проверены настройки поставщика и шесть моделей предметов/блоков.
[Подробности и команды](validation.md).

## Установка и эксплуатация

Клиент и сервер должны иметь одинаковые определения и необходимые поставщики типов.
Ресурсы устанавливаются на клиент, теги блоков — datapack в каждый мир.
Редактор экспортирует в новую/пустую папку; пользовательские миры и файлы других модов не удаляет.
Синхронизация конфигураций и доставка расширений игрокам не реализованы.

Рабочее поведение стороннего оружия, магии, инвентаря и станка не создаётся одним именем класса.
API делает такие интеграции возможными и настраиваемыми, но не заменяет их реализацию.
Ни прямой интеграции с Таумкрафтом, ни обязательной установки конкретного стороннего мода нет.

Каталог проверен на этой тестовой сборке. Совместимость со всеми модпаками, 10000 новых registry-ID
и нагрузочный тест 4096 типов не заявляются. Большой экспорт редактора пока выполняется в его UI-потоке.
