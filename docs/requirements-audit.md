# Соответствие требованиям: Item Content 1.1.1

Дата: 12 ноября 2026 года. Проверка исходников и сценариев проекта;
это не независимая внешняя сертификация.

## Назначение

Самостоятельный конструктор предметов для Minecraft 1.20.1 / Fabric.
Создаёт реальные типы предметов с ID, именем, PNG или выбранной игровой моделью,
размером стака и устойчивостью к огню. Пользователь работает в отдельном приложении.

Числовые характеристики, вычислитель, рецепты и станки сюда не входят.
Зависимости от Item Parameters нет. Совместимость означает, что предметы этого мода
можно использовать другими системами как обычные зарегистрированные предметы Minecraft.
Никакой автоматической записи настроек для других модов больше нет.

## Требования

| Требование | Реализация |
|---|---|
| Отдельный репозиторий | Собственная сборка, Git, документация и Java 17 CI |
| Без написания кода и JSON | Создать предмет, ввести имя и ID, выбрать PNG, сохранить и подготовить файлы |
| Реальный ID | Регистрация `itemcontent:<имя>` до открытия мира; без пула заглушек |
| Не занимать чужие ID | Собственный namespace; повторяющиеся ID отклоняются |
| Свои изображения | PNG с предпросмотром; экспорт текстуры, модели и resource pack |
| Готовая модель | Выбор `appearance`; модель другого мода требует этого мода на клиенте |
| Обычные свойства | Название, размер стака 1–99, огнестойкость |
| Без числовых характеристик | Нет вкладки, числового API, экспорта полей или генератора каталога Item Parameters |
| Сохранение | Открытие списка, Ctrl+S, Сохранить как, защита несохранённых изменений |
| Прежние данные | Копия полного старого документа перед сохранением; файлы игры не удаляются |
| Лицензии | MIT своего кода; Gson и FlatLaf с Apache 2.0 в редакторе |

## Интерфейс

Слева список предметов, поиск и создание. Справа одна карточка предмета и предпросмотр.
Сверху сохранение и подготовка для игры; дополнительные файловые действия в меню.
Вкладок характеристик и формул нет. Дублирование сохраняет свойства и назначает новый ID.
Новый список предметов не создаёт новый мод.

Высоту полей вычисляет FlatLaf по шрифту и отступам. Фиксированные 36 пикселей,
которые обрезали текст, убраны. Регрессионный тест воспроизводил ошибку до исправления
и проверяет внутреннюю высоту всех текстовых полей, включая spinner, после исправления.
Автотесты сами по себе не доказывают удобство интерфейса; снимки проверяются отдельно.

## Производительность и границы

Определения загружаются при старте. Собственного tick-цикла, вычислений формул или
обработки параметров отдельных экземпляров у мода нет. Desktop-экспорт работает вне Minecraft.

Пределы: 4096 типов предметов; 4 МиБ файла; 16 МиБ и 4096×4096 для одной PNG.
Это защитные границы, а не результаты нагрузочного теста. Тест 10 000 типов не выполнен.

- Клиент и сервер должны иметь одинаковые определения до подключения.
- Изменение ID требует перезапуска; автоматической доставки каталога нет.
- Самостоятельный запуск и совместный запуск с Item Parameters 1.6.2-SNAPSHOT проверены.
  Это не гарантия совместимости со всеми модпаками.
- PNG хранятся в списке как пути; экспорт содержит копии изображений.
- Модель существующего предмета разрешает Minecraft; редактор её не отрисовывает.
- Создание предмета не добавляет добычу, крафты, блоки или произвольную игровую механику.
- Экспорт в новую или пустую папку; установка в игру выполняется по инструкции.
- Чтение PNG и экспорт выполняются в потоке интерфейса; большие каталоги могут задержать окно.
- Старые сгенерированные файлы другого мода автоматически не удаляются: [миграция](migration.md).
