# Сборка и подготовка публикации

Исходники: JDK 17+, Gradle Wrapper включён. Для первой сборки нужен доступ к репозиториям зависимостей.
Готовое desktop-приложение требует Java 17+, без JDK и Gradle.

## Проверки

Из корня проекта в PowerShell:

```powershell
.\gradlew.bat build --no-daemon
.\gradlew.bat -p editor build --no-daemon
python tools/package-release.py
```

Linux/macOS: замените `.\gradlew.bat` на `./gradlew`, `python` на `python3`.
Python 3 используется только для упаковки, игра и редактор от него не зависят.

`build` проверяет runtime-парсер и совместимость с экспортом desktop-приложения.
`-p editor build` отдельно проверяет модель проекта и действия Swing без Minecraft.
`package-release.py` проверяет Java 17 bytecode, версии, лицензии и границы JAR,
затем создаёт ZIP и контрольные суммы SHA-256 в `build/distributions`.

ZIP содержит готовый редактор в `lib`, мод в `mods`, пример, инструкции и лицензии.
В Windows запускайте `run-editor.bat` после распаковки всей папки. На Linux/macOS:

```text
java -jar lib/item-content-editor-1.1.1.jar
```

GitHub Actions повторяет сборку на Java 17 и прикладывает артефакты к запуску workflow.
Это конфигурация CI; успешность удалённого запуска проверяется отдельно от локальных тестов.

## Структура

| Каталог | Назначение |
|---|---|
| `src/main` | Fabric-мод и загрузка описаний предметов |
| `src/test` | Проверки runtime и совместимости формата экспорта |
| `editor/src/main` | Независимый Swing-редактор и экспорт |
| `editor/src/test` | Тесты сохранения, экспорта, сохранности старых данных и действий интерфейса |
| `examples` | Редактируемые учебные проекты |
| `docs` | Пользовательские инструкции и результаты проверок |
| `tools` | Запуск редактора и упаковка выпуска |

`.gradle`, `.gradle-home`, `build`, `editor/build` и `run` исключены из Git.
Наличие этих каталогов на диске не означает, что они опубликованы.

## Совместимость

Имена Java-пакетов, версия конфигурации `1` и версия проекта редактора `1` сохранены.
В 1.0.3 некорректные типы JSON отклоняются вместо неявного преобразования:
размер стака `16.5`, строки вместо чисел/флагов и опечатки в ключах.
Экспорт прежнего редактора использует корректные типы и продолжает поддерживаться.


## Интерфейс 1.1.1

Редактор использует FlatLaf 3.7.2 (Apache 2.0), встроенный в его JAR.
В Minecraft-мод библиотека и классы редактора не входят. Полная лицензия включена
в `META-INF/licenses/FlatLaf-LICENSE.txt`. Базовое оформление задаёт `EditorTheme`,
сценарии карточки, поиска и сохранения — `ItemContentEditor`.

Тесты runtime компилируют `ItemProject` для проверки экспорта; GUI и тема исключены
из этого source set. Формат `.icproject` версии 1 и игровой JSON версии 1 сохранены.

Для проверки изображения окна на небольшом экране:

```text
java -jar editor/build/libs/item-content-editor-1.1.1.jar --screenshot build/editor-small.png 1280 680
```

Аргумент `--open <путь.icproject>` открывает существующий список при запуске.

## Границы модуля 1.1.1

В модели предмета и редакторе нет пользовательских числовых характеристик. Мод не обращается
к API или конфигурациям Item Parameters. Старое имя `fields` распознаётся только для безопасного
чтения старых документов; оно не экспортируется и не интерпретируется как параметры.
Резервное копирование старого документа описано в [migration.md](migration.md).

Размеры текстовых полей рассчитывает Swing/FlatLaf по шрифту и отступам. Не задавайте им
фиксированную высоту: она уже приводила к обрезке символов. Тесты измеряют свободную высоту
всех JTextField, включая поле внутри spinner. Для отдельной проверки масштаба:

```powershell
.\gradlew.bat -p editor test --no-daemon '-PtestUiScale=1.25'
.\gradlew.bat -p editor test --no-daemon '-PtestUiScale=1.5'
```
