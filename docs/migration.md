# Переход на Item Content 1.2.0

Форматы игры и редактора версии 1 продолжают читаться. Новое сохранение/экспорт использует версию 2:
добавлены типы, обычные игровые настройки и категории. Прежние предметы сохраняют ID.
Клиент и сервер обновляются вместе. `ItemSpec` сохраняет шестипараметрический конструктор;
старый `ItemContentMod.items()` возвращает обычные ConfiguredItem, новый `registeredItems()` — все типы.

Игровое поведение еды, оружия и блоков в 1.2.0 — общие настройки типа Minecraft.
Оно не возвращает удалённые индивидуальные stat-поля и не создаёт зависимость от Item Parameters.
Для старых файлов с такими полями действуют правила сохранения исходника ниже.

## Переход с выпусков до 1.1.1

Item Content создаёт предметы: ID, название, PNG или готовая модель, размер стака и огнестойкость.
Числовые характеристики и их автоматическая передача в Item Parameters удалены.
Оба мода самостоятельны; устанавливать их в паре не требуется.

## Сохранённые списки редактора

Откройте свой `.icproject` обычным способом. Имена, ID, картинки и свойства останутся.
Прежняя вкладка характеристик отсутствует. Если в документе были характеристики,
редактор сообщает, что они не используются. Открытие и экспорт не изменяют исходный файл.

При первом нажатии «Сохранить» или «Сохранить список как…» редактор сначала записывает
полную копию исходного документа рядом с ним: `<имя>.icproject.before-item-only-<номер>.bak`.
В этой копии остаются и прежние характеристики. Новый файл содержит только описания предметов.
При ошибке создания копии сохранение прерывается до изменения исходника.
Путь к резервной копии виден в подсказке строки состояния после сохранения.
Резервная копия — архив исходника, а не конфигурация для игры.

## Установленная конфигурация Minecraft

Старые `config/item-content/items.json` продолжают загружаться. Устаревший массив `fields`
игнорируется с предупреждением в журнале; сам файл не переписывается. При следующем экспорте
редактор создаст конфигурацию без `fields`.

Прежние версии могли создать `config/itemparams/items/itemcontent_generated.json`.
Новая версия не читает, не обновляет и не удаляет этот файл. Если Item Parameters установлен,
он может продолжать читать оставшийся каталог по собственным правилам.
Сам факт обновления Item Content не удаляет уже заданные параметры из другого мода.

Если старый каталог больше не нужен, сначала сохраните его резервную копию и проверьте,
что нужные определения перенесены в настройки Item Parameters. Затем уберите именно
`itemcontent_generated.json` из активной папки `config/itemparams/items` в архив вне неё.
Автоматического удаления пользовательских настроек нет.

Не меняйте ID существующих предметов при обновлении: по ним Minecraft восстанавливает
предметы из мира. Обновляйте мод и одинаковый каталог предметов на сервере и клиентах.
