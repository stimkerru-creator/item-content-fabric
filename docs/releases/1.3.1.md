Исправления по результатам независимой проверки Item Content.

**Для Windows скачайте `item-content-1.3.1-windows-x64.zip`. Java включена.**
Распакуйте весь архив и откройте `run-editor.bat`.

Исправлено:

- Дополнительные модели лука и арбалета больше не заменяют модель другого предмета с похожим именем.
- Текстуры отдельных граней блока не заменяют текстуры других блоков.
- Удаление или изменение правил добычи очищает прежние правила в выбранном мире. Старый набор сохраняется в резервной копии.
- Повреждённая геометрия и неверные преобразования модели обнаруживаются в редакторе до установки в игру.
- Установщик и экспорт отклоняют пути через Windows junction и символические ссылки.
- Все скачиваемые JAR, ZIP и контрольные суммы публикуются из одной сборки.

Настройки и формат файлов редактора сохранены. Для обновления ресурсов выберите мир при установке,
если ранее задавали правила добычи блоков. Для нескольких миров повторите установку с каждым миром.

Другие файлы:

- `item-content-1.3.1.zip` — универсальный комплект; нужна Java 17+.
- `item-content-editor-1.3.1.jar` — редактор без вложенной Java и игрового мода.
- `item-content-fabric-1.3.1.jar` — только игровой мод.
- Исходники вложенной Java и `Source code` не нужны для запуска редактора.

Minecraft по-прежнему требует Fabric Loader и Fabric API версии 1.20.1.
