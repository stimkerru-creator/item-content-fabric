Исправлена отрисовка неполных импортированных моделей: опоры и другие детали больше не скрывают соседние блоки как сплошной куб.

В **Свойствах в игре → Скрывать грани соседних блоков** доступны автоматический режим и ручной выбор.
Обычные непрозрачные кубы по-прежнему скрывают внутренние грани. Для импортированного полного куба этот режим можно выбрать вручную.
Настройка действует отдельно на каждый блок; глобальное отключение отсечения не используется.

Для исправления уже собранного мода откройте его список в редакторе 1.4.1, пересоберите JAR и замените прежний файл на клиентах и сервере с перезапуском игры.
Коллизия обычного блока остаётся кубической.

Редактор теперь работает в одном окне: повторный запуск возвращает к уже открытому редактору.
Другой список открывается в этом же окне с предложением сохранить текущие изменения.

**Windows: скачайте `item-content-1.4.1-windows-x64.zip`, распакуйте весь архив и откройте `run-editor.bat`. Java включена.**
