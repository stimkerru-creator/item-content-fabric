Редактор теперь собирает самостоятельные моды Minecraft 1.20.1 / Fabric.

**Windows: скачайте `item-content-1.4.0-windows-x64.zip`, распакуйте полностью и откройте `run-editor.bat`. Java включена.**

Нажмите **Собрать мод…**, задайте название, ID и версию, отметьте нужные предметы и сохраните JAR.
Из списка 4000 можно включить только 200: остальные предметы и каталог редактора в мод не попадают.

Игрокам достаточно готового JAR и Fabric API в папке mods. Item Content, редактор, файл проекта,
конфиги и ручное включение ресурс-пака не нужны. Модели, текстуры и правила добычи внутри JAR.
Несколько модов с разными ID можно установить вместе.

Поддерживаются встроенные игровые типы и импортированные модели Minecraft Java Block/Item.
Декоративные блоки не получают инвентарь или станочную механику автоматически.
Специальный код стороннего provider требует отдельной интеграции и автоматически не переносится.

Для прежних рабочих списков оставлен пункт Файл → Установить рабочий список через Item Content…
