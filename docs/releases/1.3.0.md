Готовый редактор предметов и блоков для Minecraft 1.20.1 / Fabric.

**Для Windows скачайте `item-content-1.3.0-windows-x64.zip`. Java включена.**
Распакуйте весь архив и откройте `run-editor.bat`. Сборка исходников и настройка пути к Java не нужны.

В этом выпуске:

- Импорт собственных моделей Minecraft Java: JSON с PNG рядом, папка ресурс-пака или ZIP.
- Сохранение геометрии, текстур, анимации текстур, родительских моделей и состояний предмета.
- Перенос импортированных ресурсов внутри файла редактора.
- Подключение каталога предметов через выбор папки сборки Minecraft.
- Готовый Windows-комплект и проверка запуска без установленной Java.

В комплекте есть мод, редактор, примеры и инструкция `docs/editor.md`.
Для Minecraft отдельно нужны Fabric Loader и Fabric API для версии 1.20.1.

Остальные файлы:

- `item-content-1.3.0.zip` — универсальный комплект с редактором JAR; требует Java 17+.
- `item-content-fabric-1.3.0.jar` — только игровой мод, без редактора.
- `OpenJDK17U-jdk-sources_17.0.21_9.tar.gz` — исходники вложенной Java, для запуска не нужны.
- `Source code` — исходники проекта для разработчиков; это не готовая программа.
